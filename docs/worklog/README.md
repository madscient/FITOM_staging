# 作業記録(worklog)

FITOM_stagingの変更・修正・調査の経緯を、月ごとに1ファイルで置く。守るべき規則は
ルートの`CLAUDE.md`に、現在の状態は`docs/STATUS.md`に書き、そこに至った経緯は
ここに書く。

- ファイル名は`YYYY-MM.md`。1件の変更・修正・調査を1つの`###`節にする
- 節をどの月に置くかは、見出しに書いた日付で決める
- 新しい記録は、該当する月のファイルの末尾に足す。節番号は最後の番号の続き
  (`3.65`以降)を使う
- 記録に書いた規則のうち、これからも守るものは`CLAUDE.md`にも現在形で書く。
  記録の側だけに規則を置かない
- 公開リポジトリなので、ローカル環境に固有の情報(手元のパス・機器名等)は書かない

## 2026年7月〜10月の節について

`3.11`〜`3.64`の節は、旧`docs/CLAUDE.md`の3節から文言を変えずに移したもので、
節番号も旧文書のまま。過去のコミットメッセージやコード中のコメントが
「3.24参照」のように番号で指しているのはこれらの節である。旧`3.1`〜`3.10`は
規則だけの節だったため、`CLAUDE.md`の規則へ統合した。

節の中の「4節」「5.5節」「2節」は旧文書の節を指す。旧4節(未解決・要確認事項)は
`docs/STATUS.md`、旧5節(運用ルール)は`CLAUDE.md`、旧2節(現在の状態)は
`docs/STATUS.md`に引き継いでいる。節の中で規則として書かれた内容は、後の節で
訂正・撤回されていることがある。現在の規則は`CLAUDE.md`を正とする。

移す際、ローカル環境に固有の名前だけを一般名へ置き換えた。
