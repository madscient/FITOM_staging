## <a id="cc323"></a>CC#32=3: wavs/rhythm ADPCM (SSGS)

PSS-680/RX11/RX21Lの3機種を収録(チップのボイステーブルが64音までのため、
ADPCM-Aバンクの6機種から3機種に絞ったもの)。全ボイス32kHz(サンプリング
コードS1S0=3)、root_noteはすべてデフォルト(none/MIDI69)。SSGSは再生
ピッチを変えられないため、ノート番号による音程変化はしない。
