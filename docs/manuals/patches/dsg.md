# DSG (CC#0=68) 音色一覧

DSG(YM2163) 波形メモリ音源 — 楽音4ch + 内蔵リズム5パート

[← バンクマップに戻る](../README.md#2-バンクマップcc0--cc32)

## <a id="cc320"></a>DSG Built-In

DSGは**ユーザー音色を持ちません**。音色は実機ROMに固定された
「波形5種 × エンベロープ4種」の20通りだけで、音色データ(HwBank)を
作成することはできません。バンクファイルは存在せず、Program Change
番号だけで音色が決まります。

**CC#32(バンク番号)の値は無視されます**。DSGにはユーザー音色の
入る余地が無いため、CC#32が何番であっても常に同じ20音色の
ビルトインバンクが選ばれます(OPLLのROM音色がCC#32=0のみ予約領域
なのとは異なります)。

```
Program Change番号の内訳:
  Prog = 波形番号 * 4 + エンベロープ番号
  音色名 = <波形名>.<エンベロープ名>
```

| Prog | 名称 | Prog | 名称 | Prog | 名称 |
|---|---|---|---|---|---|
| 0 | St.Percussive | 8 | Cl.Percussive | 16 | Hc.Percussive |
| 1 | St.Wind | 9 | Cl.Wind | 17 | Hc.Wind |
| 2 | St.Sustain | 10 | Cl.Sustain | 18 | Hc.Sustain |
| 3 | St.Plateau | 11 | Cl.Plateau | 19 | Hc.Plateau |
| 4 | Or.Percussive | 12 | Pf.Percussive | | |
| 5 | Or.Wind | 13 | Pf.Wind | | |
| 6 | Or.Sustain | 14 | Pf.Sustain | | |
| 7 | Or.Plateau | 15 | Pf.Plateau | | |

Prog 20以降を指定した音色は存在せず、無音になります。

### 波形

| 波形名 | 音色 |
|---|---|
| `St` | ストリングス |
| `Or` | オルガン |
| `Cl` | クラリネット |
| `Pf` | ピアノ |
| `Hc` | ハープシコード |

### エンベロープ

| エンベロープ名 | 挙動(サスティンペダルOFF時) |
|---|---|
| `Percussive` | 即最大 → 1/2へ減衰 → 1.2秒で消える |
| `Wind` | ゆるやかに立ち上がって保持 |
| `Sustain` | 即最大 → 1/2まで減衰して保持 |
| `Plateau` | 即最大のまま保持(鍵を離すと即消音) |

## サスティンペダル(CC#64)

DSGはサスティンのON/OFFをハードウェアで持っており、サスティンペダルが
これに直結します。踏んでいる間は鍵を離した後の余韻が1.2秒に伸びます
(`Plateau`は即消音から1.2秒の余韻へ変わり、`Percussive`は鍵を離しても
減衰が止まりません)。

## 音量の制約

DSGのチャンネル音量は**0dB / -6dB / -12dB / 消音の4段階しかありません**。
Volume(CC#7)・Expression(CC#11)・ベロシティはすべてこの4段階に丸められる
ため、他のチップのようななめらかな音量変化はできません。実機の構造上の
制約です。

## パンポット(CC#10)

DSGはパンポットを持ちません。`emu_psg_stereo`プロファイルでは2個の
チップをL/Rに固定配置してステレオ化しているため、定位はチャンネルが
どちらのチップに割り当てられたかで決まります。

## 発音範囲

最低音は約122Hz(MIDIノート47 B2のすぐ下)で、それより低いノートは
この音程で頭打ちになります。

## パフォーマンスパッチ(SwPatch)の割り当て

DSGのビルトイン音色には、ベロシティ感度やビブラートなどの
パフォーマンスパッチを個別に割り当てられます。割り当ての設定領域は
OPLLのROM音色と共有で、CC#0=40・CC#32=3の
[Built-In Voice SwPatch Meta](opll.md#cc323)に記述します
(工場出荷時点では空の状態です)。

割り当てを追加すると、CC#0=68でその音色を選択したときに、指定した
パフォーマンスパッチが自動的に適用されるようになります。

## 内蔵リズム

DSGは楽音部とは独立したレジスタ空間に5パートの内蔵リズム音源を持ち、
楽音の4chを潰すことなく同時に使えます。CC#0=112・CC#32=68で選択します。
詳細は[内蔵リズム音源の楽器選択方法](../builtin_rhythm.md#dsg-rhythm)を
参照してください。

GM2ドラムノートへ割り当て済みの
[DSG Built-in set](../drumkits.md#prog14-dsg-built-in-set)(通常の
ドラムキット、CC#0=120・Prog=14)からも鳴らせます。
